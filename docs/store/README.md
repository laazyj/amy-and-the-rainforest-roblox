# Store page kit

Everything the owner needs to set up the Release experience's store page
and its Experience Guidelines questionnaire in one sitting, with where in
the Creator Hub each goes. Nothing here is submitted by an agent: the
questionnaire, the store page and the experience's settings are the
owner's to set. Every file here is held by tier 0 to no web address
(`tools/guard store-links`) and no surname (`tools/guard names`).

| File | What it is | Where it goes |
|---|---|---|
| [questionnaire.md](questionnaire.md) | The Experience Guidelines answers, each tied to a fact and the test that backs it | Creator Hub, the experience, **Audience**, **Maturity & Compliance** |
| [description.md](description.md) | The name and the description, ready to paste | Creator Hub, the experience, **Configure**, **Basic Settings** |
| [art.md](art.md) | The icon and thumbnail specifications, which illustrations qualify under the face rule, and what to confirm by eye | Creator Hub, the experience, **Configure**, **Basic Settings** |

## One sitting, in order

1. Check the account is at least 30 days old (needed for the
   questionnaire).
2. Work through [questionnaire.md](questionnaire.md) on the Release
   experience and submit it; note the label it gives.
3. Paste the name and description from [description.md](description.md).
4. Confirm the images by eye with the checklist in [art.md](art.md), then
   set the icon and thumbnails.
5. Tick the rest of the "Compliance and settings" section of the
   [release checklist](../RELEASE_CHECKLIST.md), which owns the
   experience's settings (Max Players, Allow copying, automatic
   translation, voice chat) and says where each is.

If a Creator Hub page is not where these files say, see the note at the
top of the release checklist.
