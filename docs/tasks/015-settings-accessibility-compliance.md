# 015 — Phase 1: settings, accessibility, store page and compliance

**Kind:** mixed; the compliance items are owner actions the brief
documents and checks. **Starts after** briefs 011 and 012 merge.

## Goal

The game meets the plan's Phase 1 compliance list and accessibility
basics, and the Release store page is ready for 1.0.

## Must

1. **Settings and pause**: volume, text size, high-contrast dialogue box,
   dyslexia-friendly font option; persisted in the save; no timed reading
   anywhere (tier 1 asserts no Dialogue auto-advances).
2. **Compliance checks in tier 0**: no external URLs in content or UI
   strings; credits say "Clara" only; Max Players = 1 asserted (tier 2 or
   built-place spec); Allow Copying and automatic translation documented
   as off in the release checklist.
3. **Store page kit** under `docs/store/`: description text (no links,
   first name only), icon and thumbnail specs from Clara's illustrations
   with the face rule applied, and the Experience Guidelines questionnaire
   answers drafted for the owner to submit.
4. **Analytics** events per plan 2.3 (chapter and quest start/complete,
   collectible found, session length) through a thin adapter; tier 1
   asserts every Story event maps to an analytics event name.
5. **Release checklist** reviewed and updated so every item is either a
   check or a documented human step with its location.

## Must not

- Submit anything on Roblox on the owner's behalf.

## Done when

- Tiers green; the owner has what they need to complete the questionnaire
  and store page in one sitting.
